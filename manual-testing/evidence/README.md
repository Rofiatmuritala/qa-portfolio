# Test Evidence

This folder contains screenshots captured during manual testing of the
SauceDemo application.

The evidence supports the test execution results and documented defects.

## Evidence Categories

### Login & Authentication
Screenshots related to successful login, failed login attempts, locked
accounts, logout, and login redirection.

### Product Testing
Screenshots showing product listings, product details, product sorting,
and identified product information inconsistencies.

### Shopping Cart
Screenshots showing products being added, removed, and retained in the
shopping cart.

### Checkout
Screenshots showing checkout validation, order summary, pricing, and
successful order completion.

### Order PDF
Screenshots showing PDF generation and verification of order information.

### Application State
Screenshots showing the Reset App State defect.
