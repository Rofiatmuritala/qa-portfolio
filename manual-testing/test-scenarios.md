# SauceDemo — Test Scenarios

## 1. Login

* Verify that a user can log in with valid credentials.
* Verify that login fails with an invalid username.
* Verify that login fails with an invalid password.
* Verify that login fails when the username is empty.
* Verify that login fails when the password is empty.
* Verify that login fails when both fields are empty.
* Verify that an appropriate error message is displayed for invalid login attempts.
* Verify that a logged-in user can log out successfully.

## 2. Product Browsing

* Verify that the Products page displays available products.
* Verify that each product displays a name, price, and image.
* Verify that a user can open a product's details.
* Verify that the product details contain the expected information.
* Verify that a user can return from the product details page to the Products page.
* Verify that products can be sorted according to the available sorting options.

## 3. Shopping Cart

* Verify that a user can add a product to the cart.
* Verify that a user can add multiple products to the cart.
* Verify that the cart item count updates after adding a product.
* Verify that the selected product appears in the cart.
* Verify that a user can remove a product from the cart.
* Verify that the cart item count updates after removing a product.
* Verify that a user can continue shopping from the cart.
* Verify that the cart displays the correct product information and price.

## 4. Checkout

* Verify that a user can proceed from the cart to checkout.
* Verify that checkout requires a first name.
* Verify that checkout requires a last name.
* Verify that checkout requires a postal code.
* Verify that a user can proceed with valid checkout information.
* Verify that the checkout summary displays the selected products.
* Verify that the checkout summary displays the correct prices.
* Verify that a user can complete an order successfully.
* Verify that an order confirmation is displayed after successful checkout.

## 5. Navigation

* Verify that the main navigation menu opens correctly.
* Verify that a user can navigate back to the Products page.
* Verify that a user can navigate to the shopping cart.
* Verify that a user can log out from the application.
* Verify that a logged-out user cannot access protected pages without logging in.
