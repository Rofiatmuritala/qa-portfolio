# BUG-001 — Product Details Display Incorrect Product Information

## Severity
Medium

## Priority
High

## Environment
- macOS
- Google Chrome
- SauceDemo
- `problem_user`

## Preconditions

- SauceDemo is accessible.
- User is logged in with `problem_user`.
- User is on the Products page.

## Steps to Reproduce

1. Log in using `problem_user`.
2. Navigate to the Products page.
3. Locate Sauce Labs Backpack.
4. Note the product name and price.
5. Click the product name or image.
6. Compare the Product Details page with the Products page.

## Expected Result

The Product Details page should display the same product name,
price, description, and image as the selected product.

## Actual Result

The Product Details page displayed Sauce Labs Fleece Jacket at
$49.99 with a different image instead of Sauce Labs Backpack at
$29.99.
