# BUG-002

## Title

Product sorting functionality does not work 

## Severity

Medium

## Priority

Medium

## Environment

macOS — Google Chrome

Preconditions:

- SauceDemo is accessible.
- User is logged in successfully.
- User is on the Products page.
- Multiple products are displayed.
- The product sorting options are available.


Steps to Reproduce:

1. Open the SauceDemo application.
2. Log in with the `problem_user` account.
3. Navigate to the Products page.
4. Locate the product sorting dropdown.
5. Select one of the available sorting options.
6. Observe the product list.


Expected Result:

The products should be sorted according to the sorting option selected by the user.


Actual Result:

When using the `problem_user` account, selecting a sorting option did not change the product order, and no error message was displayed.

When using the `error_user` account, selecting a sorting option displayed the error message: "Sorting is broken! This error has been reported to Backtrace."


### Evidence

- Screenshot showing the sorting dropdown and unchanged product order when using `problem_user`.
- Screenshot showing the error message "Sorting is broken! This error has been reported to Backtrace." when using `error_user`.

### Status

Open
