# BUG-003

## Title

Reset App State does not immediately update the product button state

## Severity

Medium

## Priority

Medium

## Environment

macOS — Google Chrome

## Preconditions

- SauceDemo is accessible.
- User is logged in successfully.
- User is on the Products page.
- At least one product has been added to the cart.

## Steps to Reproduce

1. Log in to the SauceDemo application.
2. Add the Sauce Labs Backpack to the cart.
3. Verify that the product button changes to **Remove**.
4. Open the side menu.
5. Click **Reset App State**.
6. Open the shopping cart.
7. Verify that the cart is empty.
8. Return to the Products page.
9. Observe the button for the Sauce Labs Backpack.

## Expected Result

The cart should be cleared, and the Sauce Labs Backpack button should immediately change from **Remove** to **Add to cart**, reflecting the reset application state.

## Actual Result

The cart was successfully cleared, but the Sauce Labs Backpack continued to display **Remove** after Reset App State was selected. The button changed to **Add to cart** only after manually refreshing the page.

## Evidence

- Screenshot showing the cart empty after Reset App State while the Sauce Labs Backpack still displays **Remove**.
- Screenshot showing the button changed to **Add to cart** after manually refreshing the page.
