# E-Commerce Web Application — Test Plan

## 1. Project Overview

This project involves testing an e-commerce web application to evaluate
its core functionality, usability, and reliability.

## 2. Testing Objective

The objective is to verify that users can successfully log in,
browse products, manage their shopping cart, complete checkout,
and log out of the application.

## 3. Scope

### In Scope

- Login
- Product browsing
- Product sorting
- Shopping cart
- Checkout
- Order completion
- Logout

### Out of Scope

- Backend infrastructure testing
- Payment gateway integration
- Performance testing
- Security penetration testing

## 4. Testing Types

- Functional Testing
- UI Testing
- Positive Testing
- Negative Testing
- Regression Testing
- Exploratory Testing

## 5. Test Environment

- Application: SauceDemo
- Browser: Chrome
- Operating System: macOS
- Device: Laptop

## 6. Entry Criteria

Testing will begin when the application is accessible and the required
test credentials are available.

## 7. Exit Criteria

Testing will be considered complete when all planned test cases have
been executed and critical defects have been documented.

## 8. Risks

- Test environment availability
- Changes to the test application
- Limited functionality in the test environment
